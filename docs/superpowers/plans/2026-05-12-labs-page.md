# Labs Page Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Create `deploy/labs.html` — a single-screen entry point that triggers the of1 SLICC demo skill when a user clicks "Let's get started."

**Architecture:** Static HTML file matching the existing site brand (same CSS variables, fonts, header/footer patterns as `deploy/why.html`). On CTA click, the browser navigates to `https://www.sliccy.ai/handoff?upskill=https://github.com/aem-growth-adoption/of1-demo`, which SLICC intercepts to install and run the of1 demo skill.

**Tech Stack:** HTML, CSS, vanilla JS — no build step, no dependencies beyond existing Google Fonts already used across the site.

---

## File Map

- **Create:** `deploy/labs.html` — the entire labs page (head, styles, header, hero, footer)
